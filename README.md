# AoTR Build-Rechner

Build- und Stat-Rechner für das Roblox-Spiel **Attack on Titan Revolution** (Datenstand Update 5).

**Live:** https://fopoxhamster.github.io/aotr-build-rechner/

## Was er kann

- Familien (auch mehrfach), Perks mit Level und Memories eintragen
- Bestes Loadout pro Familie inkl. Extra-Slots, Divine-Perks und Capstones
- Was du leveln, verfüttern und traden solltest
- Skill-Baum zum Antippen, mit Fahrplan und Meta-Skill-Leiste
- Build-Code zum Sichern und Übertragen deiner Daten

Alles läuft im Browser, Daten bleiben lokal (localStorage). Fan-Projekt, nicht offiziell.

## Lokal starten

Einfach `index.html` im Browser öffnen. Zum Bearbeiten z. B. `vim index.html`.
